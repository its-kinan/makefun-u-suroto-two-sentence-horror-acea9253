One original two-sentence horror story (228 characters): a hallway sensor logs footsteps at 3:12 every morning, even on nights the narrator slept elsewhere — and tonight's log lists two sets. A deterministic program writes the story to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
